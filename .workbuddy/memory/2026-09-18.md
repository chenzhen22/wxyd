### 分类判断经验（下次加主题前先想清楚放哪）

- `data/`（384 个 md）是 **JDK 类 API 速查**（array-list、hash-map 这类），走 `ApiDataService`、
  对应「Java API」页——**构建工具/CLI 工具不要放这里**。
- `data-shell/`（现 47 个 md）是 **CLI 命令行工具速查**，走 `ShellScriptDataService`、
  对应「Shell 脚本学习」页。curl/wget/scp/mysql 都在这，Maven 同理放这里才对。

### 增量生效流程（加完 md 后要走完这四步）

1. 解析自检：按 `ShellScriptDataService` 的逻辑模拟一遍（见昨日备忘的格式约定），
   确认 介绍/语法/示例 三段齐全、语法段 sig 与 desc 都非空、示例段 desc 与 code 都非空、
   `^``` ` 围栏数为偶数。
2. 重新打包：`mvn clean package -pl app -DskipTests -B`
3. 重启：`java -jar app/target/app-1.0.0.jar --server.port=8090`
   （**必须带 --server.port**，原因见昨日备忘；`JAVA_TOOL_OPTIONS` 传 encoding）
4. 接口验证：先登录再查 `/shellscript/topics` 与 `/shellscript/topics/<name>`，
   确认主题数 +1、分类正确、语法/示例条数对得上。

只加 md 文件不重启的话，也可调 `POST /api/shellscript/topics/reload` 热重载（未实测）。
