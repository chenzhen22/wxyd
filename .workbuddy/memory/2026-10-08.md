## 知识库 PRD：Q1 决策定稿（全文检索范围）

**用户拍板**：索引**不要存他人 public 笔记全文**。

**落地方式**：`note_index` 新增 `content_indexed` TINYINT 标志位

| 场景 | 行为 |
|------|------|
| 搜自己的笔记 | 标题 + 正文全文命中 |
| 搜他人 public | **仅标题命中**（正文不入库） |
| 搜他人 private | 零命中（红线） |

- 写入侧判定：仅当 `ownerId == 当前登录用户` 才写 `content` 并置 `content_indexed=1`；
  他人 public 置 0 且 content 留空。`rebuildIndex` 重建时按同一规则回填。
- 这是**数据最小化**决策：public 只代表"可读"，不代表"可被全文索引"。
  正文进索引 = 库里多一份可检索副本（备份/误查/DBA 直连场景），与 private 红线的防御深度不匹配。
- 好处：将来若放开，只需重建索引 + 放开查询条件，**表结构无需变更**。
