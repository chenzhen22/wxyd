## 介绍

nc（netcat）能读写 TCP/UDP 连接，被称为网络界瑞士军刀：测端口、起临时服务端、传文件、简单协议调试样样都行。它不装在大多数系统的默认包里（yum install nc），但一旦装上就是网络排查最趁手的小工具。

核心特点：
- **客户端模式**：nc host port 连任意 TCP/UDP 服务
- **服务端模式**：-l 监听端口等连接
- **测端口标配**：-z 扫描不发包，配合 -w 超时，脚本探活首选
- **管道即协议**：连接后 stdin/stdout 直通网络，echo/d管道就能模拟请求

## 语法

### 测试端口连通

```bash
nc -zv 192.168.1.100 8090
```
- 描述: -z 只探测不发送数据、-v 显示结果，退出码 0 通/1 不通

### 带超时扫描

```bash
nc -z -w 2 192.168.1.100 8090 && echo OK || echo FAIL
```
- 描述: -w 2 秒超时，&& || 接脚本逻辑，健康检查常用写法

### 扫描端口段

```bash
nc -zv 192.168.1.100 20-100 2>&1 | grep succeeded
```
- 描述: 范围扫描，grep 过滤出开放的端口

### 临时服务端

```bash
nc -l 9999
```
- 描述: 监听 9999 等连接，连接后收到的内容打印到屏幕，Ctrl+C 结束

### 两机传文件

```bash
# 接收端
nc -l 9999 > received.tar.gz
# 发送端
nc 192.168.1.100 9999 < backup.tar.gz
```
- 描述: 重定向即传输，无认证无加密，仅限内网临时使用

### 模拟 HTTP 请求

```bash
printf 'GET / HTTP/1.0\r\nHost: example.com\r\n\r\n' | nc example.com 80
```
- 描述: 手写 HTTP 报文发请求，理解协议层排障时用

### UDP 测试

```bash
nc -u -l 53
nc -u 192.168.1.100 53
```
- 描述: -u 走 UDP；UDP 无连接，两端各敲字符可见对方回显即为通

## 示例

### 服务探活脚本

- 描述: 批量检查服务端口

```bash
# 检查一组服务的端口
for hp in "192.168.1.100 8090" "192.168.1.101 3306" "192.168.1.102 6379"; do
    set -- $hp
    nc -z -w 2 $1 $2 && echo "$1:$2 通" || echo "$1:$2 不通!"
done
```

### 定位「ping 通但服务不通」

- 描述: 网络分层排查的最后一跳

```bash
# 1. ping 通说明网络层 OK
ping -c 2 192.168.1.100

# 2. nc 测端口，不通则查服务端：监听/防火墙/安全组
nc -zv 192.168.1.100 8090

# 3. 服务端本地自测，本地通远程不通 → 防火墙问题
nc -zv 127.0.0.1 8090
```

### 临时文件传输与聊天

- 描述: 没装 rz/scp 时的应急通道

```bash
# 机器 A（接收）
nc -l 8888 > app.jar

# 机器 B（发送），传完自动断开
nc -w 3 192.168.1.100 8888 < app.jar

# 验证
md5sum app.jar
```
